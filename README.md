# AI Agent Battle — Tic-Tac-Toe

B.Tech 5th Semester — AI/ML Laboratory — Assignment X_02

## Objective

This project builds two autonomous Tic-Tac-Toe agents and investigates how search depth and heuristic design affect decision quality and computational cost.

Both agents use:
- Minimax
- Alpha-Beta pruning
- configurable depth-limited search

They differ in their heuristic evaluation functions.

## Agents

### NEXUS
- Minimax + Alpha-Beta
- Default depth: 3
- Heuristic H1: tactical threat-oriented evaluation

### TITAN
- Minimax + Alpha-Beta
- Default depth: 3
- Heuristic H2: positional/flexible-line evaluation

Neither agent uses random moves to make the experiment unfair. Randomness is used only to choose among moves with exactly equal final search scores.

Python 3.10+ is recommended. The program uses only the Python standard library and ReportLab is only needed to regenerate the PDF report.

## Run the experiment

```bash
python main.py
```

This regenerates:
- `results/results.csv` — 10-game NEXUS vs TITAN battle
- `results/depth_experiment.csv` — depth 1–4 experiment

## Methodology

The 10-game battle alternates the first player:
- odd-numbered games: NEXUS starts
- even-numbered games: TITAN starts

For the main battle both agents use depth 3. The depth experiment varies NEXUS's search depth from 1 to 4 while keeping NEXUS's algorithm and H1 heuristic fixed; TITAN remains a fixed depth-3 opponent.

For every battle game the program records:
- game number
- first player
- winner
- number of moves
- nodes evaluated by each agent
- nodes pruned by each agent
- total execution time

## Important implementation notes

The project implements Minimax and Alpha-Beta directly. No external Tic-Tac-Toe AI or search implementation is used.

Terminal positions are scored as:
- win: +100
- loss: -100
- draw: 0

At a non-terminal position where the depth limit is reached, the selected heuristic evaluates the board.

## Experimental interpretation

The results in `results/` are generated by the program and should be discussed as observations rather than predetermined outcomes. A higher win count does not automatically prove an agent is universally better; computational cost and first-player effects must also be considered.

See `report/report.pdf` for the short analysis.
